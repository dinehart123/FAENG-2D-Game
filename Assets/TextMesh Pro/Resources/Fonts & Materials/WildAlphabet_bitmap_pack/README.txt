Wild Alphabet - bitmap pack for game engines
- WildAlphabet_atlas.png + WildAlphabet_atlas.fnt : BMFont text format (Unity, Godot, LibGDX, Cocos, Phaser, etc.)
  Glyphs are drawn at 256 px per em, baseline = 205 px from line top. Lowercase letters use the uppercase art.
- glyphs/ : one transparent PNG per character (same scale), named by character.
- The Æ glyph is stored as AE.png (U+00C6 / U+00E6).
